# R02 — FIDO USB, création et utilisation de passkeys

**Statut : NON EXÉCUTÉ sur matériel — T2B1 et T3B1.**

Appliquer le [registre commun](README.md) et conserver une ligne par modèle/OS
requis. Les sorties des tests hôte/émulateur restent des preuves séparées.

## Préconditions

R01 réussi ; deux modèles ; macOS, Windows et Linux ; navigateur compatible WebAuthn et compte de test permettant une clé USB ; clé de secours indépendante.

## Étapes

1. En mode normal, relever les interfaces USB et vérifier HID FIDO + CCID, sans CDC/MSC/debuglink.
2. Depuis le compte de test, enregistrer une clé de sécurité/passkey USB ; définir le PIN FIDO si demandé, vérifier service et compte à l’écran, confirmer physiquement.
3. Fermer la session du site puis ouvrir une connexion neuve avec la clé ; vérifier l’authentification. Répéter en refusant sur l’appareil, puis en laissant expirer la demande.
4. Retirer/rebrancher, déverrouiller et se reconnecter. Tester une inscription U2F/deuxième facteur lorsque le service la propose.
5. Dans Authentification → Passkeys → Services, vérifier le compte découvrable, supprimer uniquement cette entrée, puis constater l’échec de son usage sans affecter une seconde entrée. Répéter sur chaque OS.

## Résultat attendu

Clients standards reconnaissent le périphérique ; création/assertion valides, refus/timeout ne réussissent jamais, persistance après coupure. La liste locale et la suppression ciblée correspondent aux passkeys découvrables.

## Preuves à conserver

Versions OS/navigateur, descripteurs USB, nom du service de test, captures du flux et résultats création/connexion/refus/suppression, sans données de compte privées.
