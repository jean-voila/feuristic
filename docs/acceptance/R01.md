# R01 — Boot, two buttons, PIN and languages

**Status: NOT EXECUTED as a complete hardware procedure — T2B1 and T3B1.**

Use the [shared acceptance record](README.md), with a separate result for every
required model/OS. Host and emulator output remains separate evidence.

## Preconditions

Correct model prepared with the installation guide; image without debuglink; fresh storage; flash record and screen video.

## Steps

1. Boot, observe the third-party warning and acknowledge it physically. Choose French, read the third-party notice and enter a 4–50 digit test PIN twice.
2. Visit every menu, long list and input field. Test left/right/both buttons, Back and holding left for one second. Cancel a destructive action at every stage before final confirmation.
3. Switch to English under Settings → Language and repeat navigation, then return to French. Check buttons, errors, keyboard and confirmations in both languages.
4. Lock and unlock, try one incorrect PIN and then the correct one. Change the PIN, reboot and confirm that only the new PIN unlocks storage.
5. Leave the device idle for five minutes and verify locking. Check Hardware/version against the campaign model/version.

## Expected result

No boot panic; complete, understandable text; no unexpected unavailable menus; mandatory PIN; persistent PIN change; cancellation without mutation; effective locking. The third-party warning must remain.

## Evidence to retain

Videos of both languages and confirmations, model/version, menu inventory and cancellation results. Redact every PIN from the published copy.
