# R07 — CDC-ACM, heure de session et réénumération

**Statut : NON EXÉCUTÉ sur matériel — T2B1 et T3B1.**

Appliquer le [registre commun](README.md) et conserver une ligne par modèle/OS
requis. Les sorties des tests hôte/émulateur restent des preuves séparées.

## Préconditions

R01 réussi ; TOTP de test ; ordinateurs avec heure UTC correcte ; port série identifié sur chaque OS.

## Étapes

1. Après coupure complète vérifier « Heure à synchroniser ». Ouvrir Réglages → Heure TOTP → Synchroniser par USB ; relever CDC-ACM seul et absence de FIDO/CCID.
2. Envoyer `HELLO` puis `TIME 1` suivi de l’heure Unix courante et LF avec les exemples Linux/macOS/PowerShell de `../protocols/time-sync-v1.md`, ou `uv run python tools/feuristic_time.py`. Vérifier réponse OK et retour HID+CCID.
3. Sans couper l’alimentation, ouvrir puis quitter un mode import et consulter le TOTP : l’heure doit continuer. Revenir en mode heure, envoyer une valeur 61 s plus ancienne, refuser puis accepter lors d’un second essai ; refaire avec une avance >300 s.
4. Tester TIME2, epoch avant2024/après2100, ligne >64 octets, CR/CRLF et caractères non imprimables ; comparer codes d’erreur au protocole, vérifier aucune modification sur rejet.
5. Annuler le mode sur l’appareil, puis tester le timeout de cinq minutes. Couper complètement VBUS, rebrancher : l’heure doit être à nouveau absente. Répéter sur les trois OS.

## Résultat attendu

Port temporaire standard, erreurs bornées, confirmation effective des écarts, maintien de l’heure pendant alimentation continue et invalidation après coupure, retour USB fonctionnel après chaque sortie.

## Preuves à conserver

Transcription série expurgée, timestamps UTC hôte/appareil, vidéos acceptation/refus, captures descripteurs et résultats TOTP avant/après coupure.
