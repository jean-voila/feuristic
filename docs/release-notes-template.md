**Pre-release.** feuristic is third-party firmware for the Trezor Safe 3. It is
not made or signed by SatoshiLabs. Installing it requires an irreversible
bootloader unlock — read docs/user/install.md.

Verify downloads with `SHA256SUMS` before installing. Each `.bin` is built
reproducibly from this tag by the Release workflow; the SPDX SBOM lists every
component.

Hardware acceptance status: see docs/acceptance/README.md.
