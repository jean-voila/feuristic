# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good faith, and focus on
what is best for the users' security. Harassment, discrimination and
personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub
(*Security → Report a vulnerability* can also be used for conduct issues
that must stay confidential). Reports are handled confidentially.
